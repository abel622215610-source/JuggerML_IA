# 🛡️ JuggerML (IA Edition)

**JuggerML** es una aplicación móvil desarrollada para Android orientada a la comunidad del deporte de contacto **Jugger**. Funciona como una plataforma centralizada para conectar jugadores, organizar eventos y difundir información sobre este deporte.

Este proyecto ha sido adaptado y desarrollado para la asignatura de **Fundamentos de la Inteligencia Artificial Generativa**, integrando técnicas de IA tanto en el **proceso de desarrollo** como en las **funcionalidades de la propia aplicación**.

---

## 🚀 Características Principales

* **Creación y Gestión de Partidos:** Los usuarios pueden organizar enfrentamientos locales, unirse a partidas abiertas y gestionar convocatorias.
* **Organización de Torneos:** Herramientas para la creación de brackets, gestión de equipos participantes y seguimiento de resultados en tiempo real.
* **Asistente Inteligente de Reglas (IA):** Módulo integrado impulsado por IA para resolver dudas instantáneas sobre la normativa del Jugger, arbitraje y tácticas de juego mediante procesamiento de lenguaje natural.
* **Información y Reglas del Deporte:** Sección dedicada a normativas tradicionales, guía para principiantes y recursos.
* **Autenticación y Perfiles:** Sistema de registro y gestión de perfiles de usuario conectados a la nube.

---

## 🤖 Integración de Inteligencia Artificial

En este proyecto, la IA juega un doble papel fundamental:

1. **En el Desarrollo:** Uso de asistentes de código basados en Inteligencia Artificial (como LLMs y copilotos) para la generación de estructuras, refactorización, resolución de errores y diseño lógico de componentes en Kotlin y Jetpack Compose.
2. **En la Aplicación:** Implementación de un modelo/servicio de IA para dotar a la app de un sistema experto o recomendador capaz de interactuar con el usuario y asistirle en la comprensión de las complejas reglas del Jugger.

---

## 🛠️ Tecnologías y Stack Tecnológico

La aplicación ha sido desarrollada utilizando las siguientes herramientas y tecnologías:

* **Lenguaje:** [Kotlin](https://kotlinlang.org/)
* **Interfaz de Usuario (UI):** [Jetpack Compose](https://developer.android.com/jetpack/compose) (Diseño declarativo moderno).
* **Entorno de Desarrollo:** [Android Studio](https://developer.android.com/studio).
* **Backend y Servicios IA:** [Firebase](https://firebase.google.com/) e integración con APIs/Modelos de Inteligencia Artificial
* **Control de Versiones:** Git y GitHub
* **Herramientas de IA Auxiliares:** Modelos de lenguaje para asistencia en programación y documentación.
